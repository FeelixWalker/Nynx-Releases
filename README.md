# Nynx

Windows installers, portable downloads, optional sprite packs, and automatic update files for Nynx.

[Download the latest release](https://github.com/FeelixWalker/Nynx-Releases/releases/latest)

Nynx provides a Pokemon reference workspace, maps, team and breeding tools, shiny tracking, live information, and a customizable overlay.

The existing version sequence continues for update compatibility. Saved settings and older optional 3D sprite packs remain compatible.

This is an unofficial fan companion, not affiliated with PokeMMO, Nintendo, Game Freak, or The Pokemon Company.
